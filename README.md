# College Tech Fest Microsite

## About the Project

This is a responsive college tech fest website designed to provide information about the event, speakers, schedule, and registration process. The website offers a simple and user-friendly experience across desktop, tablet, and mobile devices.

## Features

- **Home Page:** Event introduction, date, venue, and registration button.
- **Register Page:** Registration form with radio buttons and checkboxes.
- **Speakers Page:** Displays featured speakers and their details.
- **Schedule Page:** Shows the event schedule and activities.
- Responsive design for mobile, tablet, and desktop.
- Dark mode support.
- Ticket options displayed using cards.

## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript

## How to Run Locally

1. Clone the repository:

   bash
   git clone https://github.com/beherakiran/tech_fest_app.git
   

2. Open the project folder in VS Code.

3. Open `index.html` in your browser to view the website.

   Alternatively, use the **Live Server** extension in VS Code for a better development experience.
